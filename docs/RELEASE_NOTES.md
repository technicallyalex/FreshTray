# FreshTray 2.7.0

Initial public portable Windows x64 release. Includes monthly inline time logging/editing, reminders, encrypted OAuth storage, dark/light themes, docking, custom caption controls and configurable close behavior.

Verification: 44 offline core tests and Windows UI integration tests. Live provider writes are not claimed as release verification. This is an unsigned community app; known stability, accessibility and integration limits are in SECURITY.md.

All preview names and organizations are fictional. Release assets contain no account profile or credentials.
